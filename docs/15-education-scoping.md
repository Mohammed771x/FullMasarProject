## 2. ⭐ نطاق المحادثات (Scope)

**المطلوب:** لكل (صف + مسار + مادة + فرع + وضع) سجلّ محادثات مستقل.

```
scopeKey = "g{grade}|{track}|{subject}|{branch}|{mode}"

أمثلة:
  g3|علمي|احياء||شرح          ← محادثات شرح الأحياء للثالث العلمي
  g3|علمي|احياء||تلخيص        ← سجلّ مختلف تماماً
  g1|عام|احياء||شرح           ← سجلّ مختلف تماماً
  g3|علمي|رياضيات|تفاضل|وزاري ← الرياضيات تشمل الفرع
```

**تغيير أي جزء يبدّل قائمة المحادثات كاملةً** — بالضبط كما طُلب.

### التنفيذ
| الطبقة | التغيير |
|---|---|
| `ChatConversation` | حقول Hive جديدة: `grade`(7) · `track`(8) · `branch`(9) + `scopeKey` |
| `ChatStorage` | `getConversationsByScope(scopeKey)` · `countInScope()` |
| `ChatController` | `grade` · `track` · `currentScopeKey` · `setGrade()` · `setTrack()` · `setSubject()` |
| `switchContext()` | **يحفظ في Hive قبل التبديل** ثم يعيد تحميل سجلّ النطاق الجديد |

> ⚠️ **`@HiveField(7, defaultValue: 3)` إلزامي.** بدون `defaultValue` تنهار قراءة أي محادثة محفوظة قبل هذا التغيير (`null as int`). تحقّقت من الملف المولَّد: `fields[7] == null ? 3 : fields[7] as int` ✅

> 🐛 **علّة أُصلحت في الطريق:** `switchContext` كان يحفظ المحادثة في الذاكرة فقط (`_allChatsHistory`) دون Hive — فتضيع عند إغلاق التطبيق. الآن يستدعي `saveCurrentConversation()` قبل المغادرة.

> 🐛 **علّة ثانية:** وضع الرياضيات كان يستخدم `c.update()` بدل `c.switchContext()` — فلا يبدّل سجلّ المحادثات. صار `switchContext`.

## 3. القائمة الجانبية — إعادة بناء كاملة

```
📖 شعار مسار + "سفير الطالب اليمني 🇾🇪"
➕ محادثة جديدة
📚 الموارد            ← يتبع الصف والمسار — راجع [25-resources-center](25-resources-center.md)
── الصف الدراسي ──   [الأول] [الثاني] [الثالث]
── المسار ──         [علمي] [أدبي]      ← يختفي في الصف الأول
── المواد الدراسية ── قائمة الصف/المسار، غير المتاح بقفل + "قريباً"
── المحادثات ──      🏷️ شارة النطاق: "احياء · شرح · الثالث علمي"
                     القائمة (تسمية ✏️ · حذف 🗑️)
```

| الحالة | العنصر |
|---|---|
| 🗑️ حُذف | "تحديث الكود" — لم يعد هناك نظام أكواد |
| ↪️ نُقل للإعدادات | "المطور" (نافذة `ChatDialogs.showDeveloperInfo` نفسها) |
| ↪️ نُقل للإعدادات | "تفعيل الوضع الداكن" |
| 🆕 أُضيف | الشعار الرسمي · شرائح الصف · شرائح المسار · شارة النطاق |
| ✅ بقي | محادثة جديدة · الموارد · المواد · إعادة التسمية والحذف |

## 4. الربط بالـ API

`/ask` صار يرسل حقلين إضافيين:
```jsonc
{ ... , "grade": 3, "track": "علمي" }
```
**آمن اليوم:** `AskRequest` في `Backend/models.py` هو `BaseModel` عادي، و Pydantic **يتجاهل الحقول الزائدة افتراضياً**. فالخادم الحالي لا يتأثر، وعند إضافة دعم الصفوف يبدأ باستخدامهما **دون أي تغيير في الفرونت**.

## 5. الروبوت — رجع كما كان
`ScreenTip` صار بشكل فقاعة الروبوت الأصلية: `RobotWidget` + "مساعد مسار" + النص + زر "فهمت 👍".
**الفرق الوحيد:** لا يبقى دائماً — يختفي بعد 9 ثوانٍ (11 في الشات) أو يغلقه الطالب بـ ✕ أو "فهمت". ويظهر **مرة واحدة لكل شاشة** (محفوظ في SharedPreferences).

> 🔄 **حُدِّث 2026-08-27:** صار يطلّ من زاوية الشاشة على مرحلتين (الروبوت أولاً ثم فقاعته) — أسفل اليمين افتراضياً، وأعلى اليسار في شاشة الشات (`anchorTop`). التفاصيل في [25-resources-center §5](25-resources-center.md).

## 6. أماكن اختيار الصف والمسار
| المكان | ماذا |
|---|---|

| **الشريط العلوي** | يعرض المسار: "الثالث علمي • احياء • الوحدة" |
