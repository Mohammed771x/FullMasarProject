## المرحلة 1 — البنية التحتية (تُهيَّأ الآن، تُملأ لاحقاً) ⬜
| المهمة | لماذا الآن |
|---|---|
| `data/subjects/{grade}/{subject}/` + `grade` في كل مسار ودالة | إضافته لاحقاً = لمس كل ملف مرتين ([ADR-013](08-decisions.md)) |
| نقل المحتوى الحالي إلى `grade3/` وإنشاء `grade1/` `grade2/` فارغين | ترحيل نظيف مرة واحدة |
| Firebase (Auth + Firestore + Rules) وحذف `/verify-access` | كل قسم لاحق يعتمد على `uid` |
| فصل `features/future_masar/` عن الإنتاج | خطر شحن الديمو ([R-08](10-risks.md)) |
| رسالة "المحتوى قيد الإضافة 🚧" للمواد الفارغة | الصفان 1 و2 |
