# 20 — تنفيذ الوضعين: الربط الكامل ✅

**التاريخ:** 2026-08-27 · **الحالة:** منفَّذ ومختبَر (41 اختباراً + تحقق E2E بصري)

## 1. المبدأ المنفَّذ
**الطبقة الجديدة أُضيفت بجانب القديم — لا بدله.** أي طلب بلا `content_mode` يسلك المسار القديم **حرفياً** (منطق الثلاثة أشهر: concurrency، الجلسات، الوزاري، الرياضيات — كلها بلا تغيير).

## 2. الباك اند — ما أُضيف

```
Backend/
├── core/                        🆕 الطبقة الجديدة
│   ├── curriculum.py            الصفوف/المسارات/المواد (قائمة بيضاء أمنية) + توجيه الموديلات
│   ├── content_store.py         حلّ مسارات آمن (درع Path Traversal) + كاش mtime + توافق رجعي
│   ├── serializer.py            to_text العام (أي صيغة JSON → نص) + حارس حجم 30K حرف
│   ├── capabilities.py          كشف الأوضاع من شكل الملفات
│   ├── lesson_mode.py           وضع الدروس: الدرس كاملاً → الموديل (بلا embeddings)
│   ├── pages_mode.py            وضع الوحدات: نمط الأحياء معمَّماً (صفحة/برومت + FAISS)
│   └── ratelimit.py             نافذة منزلقة: 20 طلب/دقيقة لكل (IP+مستخدم) على /ask
├── tests/                       🆕 41 اختباراً (وحدة + تكامل TestClient بموديلات محاكاة)
├── api.py                       ✏️ مساران جديدان + توجيه content_mode + rate limit
└── models.py                    ✏️ حقول v3 اختيارية + تصليب (سقوف أحجام، قصّ التاريخ)
```

### المسارات الجديدة
| المسار | الوظيفة |
|---|---|
| `GET /content/subjects?grade&track` | مواد الصف/المسار |
| `GET /content/capabilities?subject&grade&track` | الوضعان المتاحان + شجرة الوحدات/الدروس — **استدعاء واحد** |
| `POST /ask` + `content_mode: "lessons"\|"pages"` | التوجيه للمعالج العام؛ غيابه = المسار القديم |

### قواعد التوجيه في `/ask`
1. فحص الكود (كما هو) ← 2. **rate limit** ← 3. `content_mode=lessons` (غير رياضيات/وزاري) → معالج الدروس العام · `content_mode=pages` → معالج الوحدات العام — **عدا أحياء الثالث العلمي فتبقى على معالجها الأصلي المجرّب** · غير ذلك → التوجيه القديم حرفياً.

### بنية ملفات المحتوى (مسطّحة — محدّثة 2026-08-27)
```
data/subjects/{المادة}/
├── lessons_mode/    ← ملف واحد، أو مجلد لكل وحدة وملف لكل درس
├── unit_mode/       ← كتاب الصفحات (صيغة الأحياء)
└── exams/           ← بنك الوزاري (لم يُمَس)
```
**بلا مجلدات صفوف:** ملف المادة يخدم كل صف تُقرّر عليه. `grade`/`track` يُستخدمان للتحقق أن المادة مقررة فقط.
الملفات القديمة **نُقلت بلا أي تعديل في محتواها** إلى مجلد وضعها، و`subject_book_path()` تحلّ الموقعين (جديد ثم قديم) فلا ينكسر أي معالج.

### الأمان المنفَّذ
| # | الحماية |
|---|---|
| 1 | **Path Traversal**: `realpath` + تحقق البقاء داخل `data/` + قائمة مواد بيضاء (اختبار `../../etc/passwd` → 404) |
| 2 | **Rate limiting**: 20/دقيقة على `/ask` بمفتاح (IP خلف البروكسي + user_id)، سقف ذاكرة، fail-open |
| 3 | **سقوف الإدخال**: content ≤ 8000، الحقول النصية محدودة، chat_history يُقص إلى 12×4000 (قصّ لا رفض — لا يكسر عميلاً قديماً) |
| 4 | **حارس حجم الدرس**: 30K حرف (أكبر درس فعلي 5.4K — هامش ×5) |
| 5 | كاش mtime محدود (256 مدخلاً) — لا تضخم ذاكرة |

## 3. الفرونت اند — ما أُضيف
| الملف | التغيير |
|---|---|
| `core/config/curriculum.dart` | **قوائم المواد الرسمية** (أدناه) + فتح كل المواد |
| `data/models/subject_capabilities.dart` 🆕 | نموذج القدرات |
| `api_endpoints` + `tutor_content_repository` | `getCapabilities()` |
| `chat_controller` | `contentMode` + `caps` + منتقيا وحدة/درس + إرسال فارغ يعني «اشرح الدرس» |
| `chat_repository` | `content_mode` في الحمولة (عند وجوده فقط) |
| `session_settings_panel` | شرائح **مصدر المحتوى** + منتقيا وضع الدروس؛ الوضع غير المتاح «قيد الإضافة» |

**قوائم المواد (المالك — 2026-08-27):**
| الصف | المواد |
|---|---|
| الأول (موحّد) | عربي · انجليزي · رياضيات · فيزياء · كيمياء · احياء · تاريخ · جغرافيا · مجتمع |
| الثاني علمي | عربي · انجليزي · فيزياء · كيمياء · احياء · رياضيات |
| الثاني أدبي | عربي · انجليزي · رياضيات · تاريخ · جغرافيا · علم الاقتصاد · علم الاجتماع |
| الثالث علمي | احياء · فيزياء · كيمياء · عربي · انجليزي · رياضيات |
| الثالث أدبي | عربي · انجليزي · رياضيات · تاريخ · جغرافيا · مبادئ علم الخرائط · الفلسفة والمنطق |

**قواعد الواجهة:** الرياضيات بلا شرائح (دروس بطبيعتها) · الوزاري يخفي الشرائح (مسار قديم) · الافتراضي = الوضع المتاح؛ وكلاهما قابل للنقر دائماً («مفتوح للكل») والخادم يرد «قيد الإضافة 🚧» عند غياب الملف.
