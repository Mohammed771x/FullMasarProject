# 19 — معمارية الوضعين: قرار معتمد ✅

**التاريخ:** 2026-08-26

> **قرار المالك:** لكل مادة **وضعان** يُختاران من القائمة الجانبية.
> **نقص المحتوى مسؤولية المالك** — لا يُعتبر عائقاً هندسياً.

## 1. الوضعان

| الوضع | الاسم في الواجهة | كيف يعمل | embeddings؟ |
|---|---|---|---|
| **أ** | **📖 وضع الدروس** | الطالب يختار الوحدة ← الدرس ← يسأل/يناقش. **الدرس كاملاً يُرسل للموديل** | ❌ لا |
| **ب** | **📄 وضع الصفحات والوحدات** | رقم صفحة ← شرح نصّها · أو وحدة + برومبت ← بحث دلالي داخلها | ✅ نعم |

**الوضعان مستقلان عن أوضاع الطلب الحالية** (شرح/تلخيص/سؤال). أي أن الإعدادات تصبح محورين:

```
مصدر المحتوى:  [📖 الدروس]  [📄 الصفحات والوحدات]
نوع الطلب:     [شرح] [تلخيص] [سؤال] [وزاري]
```
> `وزاري` مستقل عن المحورين — يبحث في بنك الأسئلة مباشرةً.

## 2. ⭐ الاكتشاف الجوهري: **لا حاجة لترحيل صيغ الدروس إطلاقاً**

**منطق المالك:** «ما بنستفيد من إيش الصياغة، لأننا بنرفع الدرس كامل في وضع الدرس.»

**صحيح — وأثبتّه:** مُسلسِل عام واحد (25 سطراً) حوّل **الصيغ الخمس كلها** إلى نص مقروء بلا أي تعديل على البيانات:

| المادة | مفاتيح الدرس (مختلفة تماماً) | النص الناتج |
|---|---|---:|
| فيزياء | `رقم_الدرس · اسم_الدرس · ملخص_قصير · الأجزاء · جملة_واحدة` | 5,168 حرف ≈ 1,722 توكن |
| كيمياء | نفسها | 1,761 حرف ≈ 587 توكن |
| عربي | نفسها | 2,216 حرف ≈ 738 توكن |
| **انجليزي** | `اسم_الدرس · المحتوى · القواعد · أمثلة_تطبيقية` | 1,918 حرف ≈ 639 توكن |
| **رياضيات** | `اسم_الدرس · تعريفات · حالات · أمثلة_محلولة · ملاحظات` | 3,799 حرف ≈ 1,266 توكن |

```python
def to_text(node, depth=0):
    """يحوّل أي بنية JSON إلى نص عربي مقروء — بلا معرفة مسبقة بالصيغة."""
    pad = "  " * depth
    if node is None: return ""
    if isinstance(node, (str, int, float)):
        s = str(node).strip()
        return f"{pad}{s}\n" if s else ""
    if isinstance(node, list):
        return "".join(to_text(x, depth) for x in node)
    if isinstance(node, dict):
        out = []
        for k, v in node.items():
            if isinstance(v, (str, int, float)):
                s = str(v).strip()
                if s: out.append(f"{pad}{k}: {s}\n")
            else:
                inner = to_text(v, depth+1)
                if inner.strip(): out.append(f"{pad}【{k}】\n{inner}")
        return "".join(out)
    return ""
```

> ✅ **كل مادة تحتفظ بصيغتها كما هي.** صفر ترحيل، صفر خطر فقدان محتوى، صفر تعديل على ملفات البيانات.

## 3. ⭐ الاكتشاف الثاني: مظروف التنقّل **موحّد أصلاً**

| المادة | `اسم_الوحدة` | `اسم_الدرس` | صيغة الصفحة | وضع الدروس | وضع الصفحات |
|---|:---:|:---:|:---:|:---:|:---:|
| احياء | ✅ 7 | — 0 | ✅ 162 | ❌ (محتوى) | ✅ **جاهز** |
| فيزياء | ✅ 7 | ✅ 41 | — 0 | ✅ **جاهز** | ❌ (محتوى) |
| كيمياء | ✅ 6 | ✅ 59 | — 0 | ✅ **جاهز** | ❌ (محتوى) |
| عربي | ✅ 1 | ✅ 11 | — 0 | ✅ **جاهز** | ❌ (محتوى) |
| انجليزي | ✅ 1 | ✅ 17 | — 0 | ✅ **جاهز** | ❌ (محتوى) |
| رياضيات | ❌ لا وحدات | ✅ 63 ملفاً | — 0 | ⚠️ يحتاج طبقة وحدات | ❌ (محتوى) |

**`اسم_الوحدة` موجود في كل المواد، و`اسم_الدرس` موجود في كل مادة لها دروس.**
**المظروف الذي نحتاجه للتنقّل موجود بالفعل — لا شيء يُبنى من الصفر عدا طبقة وحدات للرياضيات.**

## 4. المبدأ الحاكم: **كشف القدرات من البيانات، لا ترميزها في الكود**

```python
def capabilities(book) -> dict:
    """يقرأ الملف ويقرر أي وضع متاح — بلا أي قائمة مواد مكتوبة يدوياً."""
    units = book if isinstance(book, list) else book.get("الوحدات", [])
    has_lessons = any(u.get("الدروس") for u in units)
    has_pages   = any(u.get("الصفحات") for u in units)
    return {"lessons": has_lessons, "pages": has_pages, "units": len(units)}
```

**الأثر:** حين يضيف المالك صفحات للفيزياء، **يظهر وضع الصفحات تلقائياً بلا سطر كود واحد.** وحين يضيف دروساً للأحياء، يظهر وضع الدروس تلقائياً. **الكود لا يعرف أسماء المواد إطلاقاً.**

## 5. خطة التنفيذ

### الباك اند

| 3 | `GET /subjects/capabilities?grade&track&subject` | `api.py` |

### الفرونت اند

## 6. الإيجابيات

| # | |
|---|---|
| 1 | **صفر ترحيل بيانات** — كل مادة تبقى بصيغتها. لا خطر فقدان محتوى إطلاقاً |
| 2 | **وضع الدروس أدق من الـ embeddings** — الطالب يحدد الدرس، فلا استرجاع خاطئ |
| 3 | **أرخص**: أكبر درس 1,800 توكن مقابل استرجاع + سياق أوسع |
| 4 | **أسرع**: بلا تشفير ولا بحث — صفر عبء على المعالج |
| 5 | **ذاكرة أقل**: وضع الدروس لا يلمس PyTorch إطلاقاً |
| 6 | **يتوسّع تلقائياً**: أضف المحتوى ← يظهر الوضع بلا كود |
| 7 | مشاكل `رقم_الوحدة` و`عدد_الدروس` **تصبح غير ذات صلة** — لا نستخدمها؛ نعرض الأسماء فقط |

## 7. المخاطر المتبقية

| # | الخطر | الحجم | التخفيف |
|---|---|---|---|
| 1 | **الرياضيات بلا طبقة وحدات** | متوسط | الفرع = وحدة، الملف = درس. سكربت فهرسة بلا لمس الملفات |
| 2 | ملف رياضيات **بلا امتداد `.json`** (`مبدأ العد`) — غير مرئي | صغير | إعادة تسمية (تعديل بيانات، بإذن المالك) |
| 3 | ملف رياضيات يستخدم `اسم_درس` بدل `اسم_الدرس` | صغير | المُسلسِل يقبل الاثنين |
| 4 | **مسافات بادئة** في أسماء الوحدات | صغير | `.strip()` عند المطابقة (موجود جزئياً) |
| 5 | `to_text` قد يُخرج مفاتيح تقنية للموديل (`رقم_الدرس: 1`) | صغير | قائمة تجاهل للمفاتيح غير المفيدة |
| 6 | **دروس بلا حد أقصى مستقبلاً** — درس ضخم قد يتجاوز السياق | متوسط | حارس: إن تجاوز الدرس N حرفاً، قصّ أو ارجع للـ embeddings |
| 7 | تغيير `subjects/*.py` الستة يمسّ منطقاً يعمل مع 2,500 مستخدم | **الأكبر** | إضافة مسار جديد **بجانب** القديم لا بدله؛ الأوضاع الحالية لا تُمَس |

## 8. الحكم

**القرار ممتاز، وأفضل من خطة التوحيد الكاملة التي اقترحتها سابقاً:**

| | خطة التوحيد الكامل | **قرار المالك** |
|---|---|---|
| ترحيل البيانات | كل الملفات | **صفر** |
| خطر فقدان محتوى | حقيقي | **معدوم** |
| الجهد | 2–3 أيام ترحيل + تحقق | **مُسلسِل 25 سطراً** |
| التوسّع لمواد جديدة | يحتاج ترحيل | **تلقائي** |
| دقة الإجابة | embeddings | **الدرس المحدد صراحةً — أدق** |

⚠️ **الشرط الوحيد:** المسار الجديد يُضاف **بجانب** الحالي لا بدله. الأوضاع التي تعمل اليوم تبقى تعمل حرفياً، والوضع الجديد اختيار إضافي.
