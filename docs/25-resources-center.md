# 25 — مركز الموارد حسب الصف + صيانة المحادثة ✅

**التاريخ:** 2026-08-27 · **الباك اند:** لم يُمَس · **الاختبارات:** 14/14 ✅ (Flutter)

## 1. المشكلة

مركز الموارد كان **قائمة ثابتة داخل النافذة نفسها**: ست مواد بروابط الثالث الثانوي العلمي فقط. طالب الصف الثاني يفتح «الموارد» فيجد مواد ليست مواده.

## 2. الحل — `core/config/resources.dart` 🆕

**مصدر وحيد للروابط**، بنفس فلسفة `curriculum.dart`:

```
مواد النافذة = Curriculum.subjectsFor(grade, track)   ← نفس قائمة القائمة الجانبية حرفياً
روابط كل مادة = Resources.forSubject(grade, track, subject)
مفتاح النطاق  = "g{الصف}|{المسار}"   مثل: g3|علمي · g2|أدبي · g1|عام
```

| العنصر | الدور |
|---|---|
| `ResourceLink(name, url)` | رابط واحد |
| `_byScope` | خريطة: نطاق ← مادة ← روابطها |
| `forSubject()` | روابط مادة (قائمة فارغة = «قريباً») |
| `hasAny()` | هل لهذا الصف/المسار أي روابط أصلاً؟ |
| `displayName()` | إيموجي + اسم مقروء (`عربي` ← «📜 اللغة العربية») |
| `scopeKey()` | يمرّ بـ`normalizeTrack` — فالأول الثانوي لا يُنتج مفتاحاً بمسار |

### ➕ إضافة روابط صف جديد
افتح `resources.dart`، واملأ مفتاح نطاقه (مثلاً `"g2|علمي"`) بمواده وروابطها. **لا تُلمس أي شاشة** — النافذة تلتقط الإضافة تلقائياً.

### حالة اليوم
| النطاق | الروابط |
|---|---|
| **g3\|علمي** | ✅ ست مواد (نفس روابط Drive السابقة، بلا تغيير) |
| g1\|عام · g2\|علمي · g2\|أدبي · g3\|أدبي | 🚧 المفاتيح جاهزة فارغة |

## 3. النافذة

```
📁 مركز الموارد
   الثاني الثانوي · أدبي        ← 🏷️ شارة النطاق (تختفي «المسار» في الصف الأول)
   🚧 موارد الثاني الثانوي · أدبي قيد التجهيز — المواد أدناه جاهزة…
   ┌ 📜 اللغة العربية      [قريباً] ┐   ← ExpansionTile معطّلة بلا سهم
   ┌ 🔤 اللغة الإنجليزية   [قريباً] ┐
   …كل مواد الصف/المسار بالترتيب نفسه
```

مادة بروابط ⇒ تُفتح وتعرض روابطها كما كانت. مادة بلا روابط ⇒ شارة **«قريباً»** ولا تُفتح.

## 4. 🐛 صيانة واجهة المحادثة (نفس الجولة)

| # | العلّة | الإصلاح |
|---|---|---|
| 1 | **الكلام تحت صورتين ينزاح للجهة المقابلة** | `Column.crossAxisAlignment` كان مقلوباً: التطبيق **RTL**، وفيه `start` = يمين و`end` = يسار. فرسالة الطالب كانت تُحاذي **يسار** عمودها. مقيسٌ في الاختبار: حافة الفقاعة اليمنى كانت **613** بدل **784** — انزياح 171 بكسل يظهر فقط حين تكون الصور أعرض من النص (أي مع صورتين) |
| 2 | **تفاوت حجم الصورتين** | كانتا بعرض ثابت وارتفاع حرّ ⇒ حافتان سفليتان غير متساويتين. الآن **مربّعان 120×120** عند وجود صورتين، والصورة المفردة تحتفظ بنسبتها |
| 3 | **آخر رسالة تختفي خلف الأزرار** | حشوة القائمة السفلية كانت ثابتة `160` بينما يعلو خانةَ الكتابة أحياناً زرّا الوزاري («أكمل/إيقاف») أو زر «ابدأ الشرح الذكي» مع تنبيهه. صارت `160 + bottomExtra` يحسبها `MainChatScreen` من نفس شروط الإظهار |
| 4 | **تأكيد Flutter في بطاقات الموارد** | `ListTile` داخل `Container` ملوّن ⇒ «ink splashes may be invisible» (9 استثناءات في اختبار واحد). صارت البطاقة `Material` ملوّناً — التموّج يظهر والتأكيد اختفى |
| 5 | شارة التحميل في بطاقة المورد بلون `Colors.white` الصريح | صارت `AppColors.surfaceWhite` — تتبع الوضع الداكن |

> **مقلوبة أيضاً وأُزيلت:** `Row.mainAxisAlignment` في الفقاعة (`end` للطالب) — كانت بلا أثر لأن `mainAxisSize: min`، وتركها فخّ لمن يعدّل لاحقاً.

## 5. 🤖 تلميح الشاشة — الروبوت يطلّ من الزاوية ويتكلّم

**الشكوى:** التلميح كان شريطاً عرضياً يُزرع أسفل الشاشة بلا هوية — والروبوت مجرّد أيقونة صغيرة داخل الشريط.

**الآن — مرحلتان تجعلان الكلام يبدو صادراً منه:**

```
١)  🤖  يقفز الروبوت من الزاوية (slide + scale · easeOutBack) وهو يـلـوّح 👋
٢)  بعد 380ms تنفتح الفقاعة **من زاويته نفسها** (AnimatedScale alignment)
    وذيل صغير يشير إليه ⇒ ويتحوّل الروبوت إلى وضع «الكلام» (فمه يتحرّك) 🗣️
الخروج معكوس: تنطوي الفقاعة، وبعد 180ms ينسحب الروبوت للزاوية.
```

| الزاوية | أين | مَن يستعملها |
|---|---|---|
| **أسفل اليمين** (الافتراضي) | الروبوت أسفل اليمين، الفقاعة فوقه والذيل لأسفل | كل الشاشات |
| **أعلى اليسار** (`anchorTop`) | الروبوت أعلى اليسار، الفقاعة تحته والذيل لأعلى | شاشة الشات — أسفلها لوحة الإعدادات وخانة الكتابة |

- حجم الروبوت 42 ← **56** (صار شخصية لا أيقونة داخل صف).
- الذيل `_TailPainter` مثلّث 18×9 بلون `surfaceWhite` يلتحم بالفقاعة (إزاحة 1 بكسل).
- كل المحاذاة بـ`Alignment` **فيزيائية صريحة** (يمين/يسار) لا `start/end` — تفادياً لانقلاب RTL نفسه الذي أصلحناه في §4.
- ما لم يتغيّر: «مرة واحدة لكل شاشة» في SharedPreferences · الإخفاء التلقائي · ✕ و«فهمت 👍» · `ScreenTip.resetAll`.
