# 00 — نظرة عامة

## ما هي "مسار"؟
منصة تعليمية عربية RTL للطالب اليمني، من **الأول الثانوي** إلى **ما بعد التخرج والمنح**.
النواة: مساعد ذكاء اصطناعي يشرح ويلخّص ويجيب ويسترجع أسئلة وزارية من الكتب المدرسية عبر RAG.

- **المستخدمون:** ~2,000–2,500 نشط
- **التقنية:** Flutter (أندرويد أولاً) + FastAPI على Hugging Face Spaces
- **اللغة:** عربية بالكامل، RTL، خط Cairo

## خريطة المستودع
```
FullMasarProject/
├── masar_platform_v3.md      وثيقة المواصفات الأصلية
├── docs/                     📚 هذه الوثائق
├── Backend/                  ✅ FastAPI — 4,951 سطر Python
├── frontendappversion/       ✅ ★ الأساس المعتمد — بنية نظيفة
└── webversion/               ⚠️ نسخة قديمة — مرجع فقط
```
