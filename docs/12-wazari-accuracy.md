# 12 — دقّة الوزاري: التشخيص والحل ⭐

## 1. المشكلة كما وصفها المالك
> «لو كتب مثلاً *القوة الكهربائية*، ممكن يطلع له سؤال في وحدة ثانية… بس تخربل غلط.»

**التشخيص: صحيح تماماً، والسبب ليس في الذكاء الاصطناعي — بل في أن الأسئلة غير موسومة.**

## 2. السبب الجذري

### (أ) ملفات الامتحانات لا تحمل أي وسم للدرس أو الوحدة
```jsonc
// data/subjects/احياء/exams/2024.Json
{ "سنة_الامتحان": 2024,
  "الجزء": "الجزء الأول",
  "نوع_السؤال": "أكمل الفراغات الآتية",
  "الاسئلة": ["1- غشاء الأم الحنون نسيج رقيق...", ...] }
```
**لا `الدرس`. لا `الوحدة`.** لا يوجد ما يُفلتر به أصلاً.

### (ب) لذلك لم يبق إلا مطابقة الكلمات — بعتبة = 1
```python
# Backend/subjects/common.py:462  filter_and_rank_exams
user_keywords = extract_keywords(user_text)
for q in questions:
    score = 0
    for kw in user_keywords:
        if kw in q_text: score += 1
    if score > 0:                       # ← 🔴 كلمة واحدة تكفي
        scored_questions.append((score, q))
```
`extract_keywords` = تطبيع + تقسيم + كلمات ≥3 أحرف. لا قائمة كلمات شائعة (stopwords).

**التتبّع الكامل لـ "القوة الكهربائية":**
1. `normalize_arabic` → إزالة "ال" والتشكيل → `"قوه كهربائيه"`
2. `extract_keywords` → `["قوه", "كهربائيه"]`
3. أي سؤال فيه **"قوه"** فقط → `score = 1 > 0` → **يظهر**
4. النتيجة: قوة الجاذبية، القوة المغناطيسية، القوة في الميكانيكا… كلها تظهر

### (ج) المفارقة: **الرياضيات محلولة أصلاً في مشروعك**
```jsonc
// data/subjects/رياضيات/exams/هندسة/2018.json
{ "سنة_الامتحان": "2018",
  "الدرس": "القطع المكافئ",          // ✅ ← الوسم
  "الاسئلة": [{"نص_السؤال": "...", "الحل": "..."}] }
```

**فلترة مباشرة بالدرس. صفر ذكاء اصطناعي. صفر embeddings. دقة 100%. زمن استجابة صفر.**

> 🎯 **الخلاصة: الحل الذي تبحث عنه مطبَّق عندك بالفعل — في الرياضيات فقط. المطلوب تعميمه.**

### (د) عربي وإنجليزي: لا تعمل إطلاقاً
صيغتهما مختلفة (`الأقسام` / `أقسام_الأسئلة`) و`collect_exam_questions_by_years` يبحث عن مفتاح `الاسئلة` فقط → **يرجع صفر أسئلة**. الوزاري في هاتين المادتين معطّل بصمت.

## 3. تقييم فكرة "إعادة الأسئلة للذكاء الاصطناعي ليفلترها"

**الفكرة:** بعد المطابقة، تُرسل الأسئلة الناتجة + اسم الدرس + بحث الطالب إلى الموديل ليختار المرتبط فقط.

**الحكم: تعالج العَرَض لا المرض — ولا تحل نصف المشكلة.**

| | فلترة AI في كل طلب | وسم مرة واحدة |
|---|---|---|
| التكلفة | كل بحث وزاري يستهلك توكنات | **~$0.30 مرة واحدة للأبد** |
| زمن الاستجابة | **+3 إلى 8 ثوانٍ** لكل بحث | **صفر** |
| الثبات | نفس البحث → نتائج مختلفة | متطابقة دائماً |
| المخاطرة | يحذف أسئلة صحيحة أو يهلوس | مراجَع وقابل للتصحيح |
| **الاستدعاء (Recall)** | 🔴 **لا يُصلَح** | ✅ **يُصلَح** |

### 🔴 العيب القاتل: الفلترة تحسّن الدقة ولا تحسّن الاستدعاء

الموديل **لا يرى إلا ما أعطته له مطابقة الكلمات**. السؤال الذي أخطأت المطابقة في التقاطه — لأنه صاغ الفكرة بألفاظ أخرى — **يبقى ضائعاً، والموديل لا يستطيع استرجاعه**.

مثال حقيقي: طالب يبحث "القوة الكهربائية"، وسؤال وزاري يقول *«يؤثر مجال شحنة نقطية على شحنة أخرى بمقدار…»* — لا يحتوي "قوه" ولا "كهربائيه". **المطابقة تسقطه، والفلترة لا تعرف بوجوده.**

الوسم يحل الاثنين: كل سؤال في الدرس يظهر، ولا شيء من خارجه.

## 4. ✅ الحل الموصى به: الوسم مرة واحدة دون عمل يدوي

> ردّاً على «موضوع إنه لكل درس صعب بيكون شوي علي»: **لن تسم شيئاً بيدك.** سكربت يعمل مرة واحدة، وأنت تراجع فقط.

### السكربت
```python
# tools/tag_exam_questions.py  (يُشغَّل يدوياً، ليس جزءاً من الـ API)
lessons = get_lessons(grade, subject)        # من الكتاب الموحّد
for q in all_questions:
    prompt = f"""أمامك سؤال وزاري ومنهج المادة.
اختر الدرس الذي ينتمي إليه السؤال من القائمة فقط.
إن لم ينتمِ لأي درس بوضوح أجب: غير_محدد

```

### خط المراجعة
1. يعمل السكربت → يكتب `الدرس` في ملفات JSON
2. **لوحة التحكم تعرض الأسئلة مجمّعة بالدرس** مع تمييز `مصدر_الوسم: ai`
3. تراجع، تصحّح الخطأ بسحب السؤال لدرسه الصحيح → `مصدر_الوسم: human`
4. `غير_محدد` تُراجَع يدوياً (متوقع 5–10%، أي ~100 سؤال)

**بعدها الاسترجاع يصبح:**

دقة 100% · زمن صفر · نفس منطق الرياضيات الذي يعمل عندك اليوم.

## 5. تحسينات مصاحبة (رخيصة)

### (أ) رفع العتبة + كلمات شائعة — **إصلاح فوري بسطرين**
حتى قبل الوسم، هذا وحده يقلّل الضجيج كثيراً:
```python
STOPWORDS = {"التي","الذي","عند","بين","على","من","في","مع","كل","بعض",
             "اذكر","عرف","وضح","اشرح","علل","قارن","احسب","ماذا","كيف"}

def extract_keywords(query):
    words = [w for w in normalize_arabic(query).split()
             if len(w) >= 3 and w not in STOPWORDS]
    return words

# وفي filter_and_rank_exams:
min_hits = max(1, len(user_keywords) // 2)   # نصف الكلمات على الأقل
if score >= min_hits:
    scored_questions.append((score, q))
```
> ملاحظة: `filter_exams_smart(min_hits=2)` موجودة في `common.py:525` وتفعل هذا تقريباً — **لكن لا أحد يستدعيها.** كود ميت.

### (ب) بحث دلالي احتياطي للأسئلة `غير_محدد`
الأسئلة التي فشل وسمها تبقى قابلة للوصول ببحث FAISS ضمن المادة — شبكة أمان لا آلية أساسية.

### (ج) توحيد صيغة امتحانات عربي وإنجليزي
شرط لتشغيل الوزاري فيهما أصلاً.
