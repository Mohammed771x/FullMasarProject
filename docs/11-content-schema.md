## 4. ✅ الصيغة الموحّدة المستهدفة

صيغة واحدة لكل المواد، تدعم **الوضعين معاً**:

```jsonc
{
  "grade": 3,
  "subject": "احياء",
  "book_title": "الأحياء — الثالث الثانوي",
  "schema_version": 1,
  "units": [{
    "unit_no": 1,
    "unit_name": "التنظيم الهرموني",
    "page_from": 41, "page_to": 78,
    "lessons": [{
      "lesson_no": 1,
      "lesson_name": "الهرمونات النباتية",
      "page_from": 41, "page_to": 47,
      "summary": "...",          // ملخص_قصير
      "one_liner": "...",        // جملة_واحدة
      "pages": [                 // ← وضع الصفحة
        { "page_no": 41, "text": "..." }
      ],
      "parts": [                 // ← وضع البرومبت (الأجزاء)
        { "type": "نقاط_مهمة", "title": "...", "content": ["..."] }
      ]
    }]
  }]
}
```

**لماذا هذه الصيغة:**
- `pages[]` تحت الدرس → **وضع الصفحة يعمل في كل مادة**
- `lessons[]` تحت الوحدة → **وضع البرومبت يعمل في كل مادة**
- `page_from/page_to` على الدرس → **الجسر بين الوضعين**: رقم الصفحة يعرف درسه، والدرس يعرف صفحاته
- `schema_version` → هجرة مستقبلية آمنة

**ما يلزم لكل مادة:**
| المادة | الناقص | الحل |
|---|---|---|
| احياء | الدروس | تقسيم الـ162 صفحة إلى دروس (مرة واحدة بالـ AI + مراجعة) |
| فيزياء · كيمياء | أرقام الصفحات | تُضاف عند الرقمنة، أو يبقى وضع الصفحة معطلاً لها |
| عربي · انجليزي | الاثنان | مراجعة يدوية (11 و17 درساً — صغيرة) |

## 5. بنية الصفوف المستهدفة

```
data/subjects/
├── grade1/{subject}/...     ← بنية جاهزة، محتوى لاحقاً
├── grade2/{subject}/...     ← بنية جاهزة، محتوى لاحقاً
└── grade3/{subject}/...     ← كل المحتوى الحالي يُنقل هنا كما هو
```
> ⚠️ **`grade` يُضاف الآن في كل مسار وكل دالة، حتى قبل وجود محتوى للصفين الأول والثاني.** إضافته لاحقاً تعني لمس كل ملف في `subjects/` مرة ثانية.
