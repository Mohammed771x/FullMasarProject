# 21 — المواد الجديدة: ملف معالج مستقل لكل مادة ✅

**التاريخ:** 2026-08-27 · **الاختبارات:** 64/64 ✅

## 1. القرار
كل مادة جديدة لها **ملف برمجي مستقل** في `subjects/` ببرومبتاته الكاملة — يُعدَّل بحرية دون أن يتأثر غيره.
المواد الموجودة (احياء · فيزياء · كيمياء · عربي · انجليزي · رياضيات) **لم تُمَس** وتُعاد لكل الصفوف والمسارات كما هي.

## 2. الملفات المُنشأة

| الملف | المادة | الصفوف |
|---|---|---|
| `subjects/history.py` | تاريخ | الأول · الثاني الأدبي · الثالث الأدبي |
| `subjects/geography.py` | جغرافيا | الأول · الثاني الأدبي · الثالث الأدبي |
| `subjects/society.py` | مجتمع | الأول |
| `subjects/economics.py` | علم الاقتصاد | الثاني الأدبي |
| `subjects/sociology.py` | علم الاجتماع | الثاني الأدبي |
| `subjects/philosophy.py` | الفلسفة والمنطق | الثالث الأدبي |
| `subjects/cartography.py` | مبادئ علم الخرائط | الثالث الأدبي |

### بنية كل ملف
```python
SUBJECT = "تاريخ"

def prompt_explain() -> str:   # 🎓 برومبت الشرح   — منسوخ حرفياً من الأحياء
def prompt_summary(level) -> str:  # 📝 برومبت التلخيص (5 مستويات)
def prompt_qa() -> str:        # ❓ برومبت السؤال

async def handle_history_request(req, clients): ...
```

**البرومبتات نصوص كاملة داخل كل ملف** — لا مراجع مشتركة. تعديل برومبت التاريخ لا يمسّ الجغرافيا (مغطّى باختبار `test_prompts_are_independent_per_subject`).

**مصدر البرومبتات:** برومبت الأحياء للثالث الثانوي حرفياً، مع تغيير اسم المادة، وتعديل بندٍ واحد: بند المعادلات الرياضية استُبدل بـ«التواريخ والأرقام والمصطلحات» لملاءمة المواد النظرية.

## 3. آلية العمل
```
POST /ask  →  فحص الكود  →  rate limit  →  المادة في NEW_SUBJECT_HANDLERS؟
                                              ├─ نعم → تحقق أنها مقررة على الصف (وإلا 400)
                                              │        → معالج المادة المستقل
                                              │           ├─ content_mode=lessons → lesson_mode + برومبتات المادة
                                              │           └─ content_mode=pages   → pages_mode  + برومبتات المادة
                                              └─ لا  → المسار القديم كما هو
```
عند غياب `content_mode` (عميل قديم) يختار المعالج تلقائياً: الدروس إن وُجد ملفها، وإلا الوحدات.

### تعديل جوهري في الطبقة العامة
`core/lesson_mode.handle()` و`core/pages_mode.handle()` صارا يقبلان `prompts=` اختياري — وحدة المادة تُمرَّر فتُستخدم برومبتاتها. **بلا `prompts` يعمل كما كان تماماً** (توافق رجعي كامل).

## 4. توجيه الموديلات
كل المواد النظرية الجديدة → **Gemini Flash-Lite** (`core/curriculum.py: MODEL_ROUTING`). عدّل السطر لتغيير موديل أي مادة.

| | |

## 7. ملاحظة صيانة
البرومبتات مكرّرة عمداً عبر 7 ملفات (≈40 سطراً لكل واحد) — **هذا هو المطلوب**: استقلال التحرير. الثمن أن تحسيناً عاماً يلزم تكراره يدوياً في كل ملف.
