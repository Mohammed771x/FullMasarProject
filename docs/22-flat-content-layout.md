**التاريخ:** 2026-08-27 · **الاختبارات:** 66/66 ✅

## 1. البنية المعتمدة

```
data/subjects/{المادة}/
├── grade1/                          ← الأول موحّد (بلا مجلد مسار)
│   ├── lessons_mode/                📖 وضع الدروس
│   └── unit_mode/                   📄 وضع الوحدات/الصفحات
├── grade2/{علمي|أدبي}/{lessons_mode|unit_mode}/
├── grade3/{علمي|أدبي}/{lessons_mode|unit_mode}/
└── exams/                           📝 بنك الوزاري (لم يُمَس)
```

**تُنشأ تركيبة (صف، مسار) فقط حيث المادة مقررة:**
- احياء → `grade1` · `grade2/علمي` · `grade3/علمي` (بلا أدبي)
- انجليزي → الخمس تركيبات كاملة
- مجتمع → `grade1` فقط
