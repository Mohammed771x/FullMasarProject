## 2. الباك اند

### `core/firebase_auth.py` 🆕
⭐ **التحقق من التوكن لا يحتاج Service Account إطلاقاً** — فقط معرّف المشروع ومفاتيح جوجل العامة (`google-auth`). الـService Account مطلوب فقط لكتابة عدّاد الحصة.

```
Authorization: Bearer <idToken>
   ↓ فحص التوقيع + aud + iss + exp
   ↓ {uid, email, email_verified, provider, is_guest}
   ↓ provider == "password" وبريد غير مفعّل ⇒ 403
```

### `core/quota.py` 🆕
| المستخدم | الحد | المستند |
|---|---|---|
| طالب مسجَّل | **50/يوم** | `usage/{uid}_{yyyy-mm-dd}` |
| زائر | **5 تراكمية** (لا يومية — وإلا التفّ عليها بالانتظار) | `usage/guest_{uid}` |
| مستخدم بالكود القديم | خارج الحصة | — |

**التخزين:** Firestore عبر Admin SDK، وعند غياب الاعتماد → الذاكرة مع تحذير في اللوج. `fail-open` عند أي عطل: نظام الحماية لا يجوز أن يُسقط الخدمة، وتحديد المعدل خط الدفاع الثاني.

### `api.py`
```python
identity, error = _authenticate(request, req)   # توكن أولاً، فالكود
if not identity["legacy"]:
    allowed, _ = quota.check_and_consume(uid, is_guest)   # 429 + quota_exceeded
```
**انتقال آمن:** الكود القديم يظل يعمل حتى تُحدَّث تطبيقات الطلاب، ويُطفأ بمتغيّر بيئة واحد:
```bash
AUTH_ALLOW_LEGACY_CODE=0
```

## 9. 🐛 «تعذّر الدخول بجوجل» — التشخيص والإصلاح

**العَرَض:** الضغط على «المتابعة بحساب جوجل» يرد *«تعذّر الدخول بجوجل. تأكد من اتصالك بالإنترنت»* رغم أن الإنترنت يعمل.

**السبب:** تلك الرسالة كانت `catch` عاماً يبتلع **كل** الأخطاء ويسمّيها مشكلة إنترنت. والسببان الحقيقيان:

| المنصة | العلّة | الدليل | الإصلاح |
|---|---|---|---|
| **أندرويد** | **بصمة SHA-1 غير مسجّلة** في Firebase | `google-services.json` فيه `oauth_client` من **النوع 3 (ويب) فقط**، ولا يوجد عميل أندرويد (النوع 1) بـ`certificate_hash` — وهذا لا يظهر إلا بعد تسجيل البصمة | تسجيل البصمة ثم **إعادة تنزيل** `google-services.json` (§9.1) |
| **iOS** | **مخطط URL مفقود** | `Info.plist` كان **بلا `CFBundleURLTypes` إطلاقاً**، فلا طريق لجوجل ليعيد النتيجة للتطبيق | ✅ أُضيف `REVERSED_CLIENT_ID` من `GoogleService-Info.plist` |

### 9.1 خطوات الأندرويد (تحتاجك)
```bash
cd android && ./gradlew signingReport      # يطبع SHA1 و SHA256 لكل نسخة
```
ثم: Firebase Console ← Project settings ← تطبيق أندرويد ← **Add fingerprint** ← ألصق SHA-1
ثم **نزّل `google-services.json` الجديد** وضعه في `android/app/` ← **بناء كامل** (لا Hot Reload).

> ⚠️ **سجّل بصمتين لا واحدة:** بصمة **debug** (للتجربة) وبصمة **release** (للنشر).
> وإن نشرت عبر Google Play بـ**App Signing**، أضف كذلك بصمة **مفتاح جوجل** من
> Play Console ← App integrity — وإلا عمل الدخول عندك وفشل عند الطلاب.

### 9.2 الرسائل صارت تقول الحقيقة
| الحالة | الرسالة الآن |
|---|---|
| إعداد ناقص (SHA-1 / URL scheme) | «إعداد الدخول بجوجل غير مكتمل… جرّب البريد وكلمة المرور» |
| `MissingPluginException` | «أوقف التطبيق تماماً وأعد تشغيله (لا Hot Reload)» — يحدث بعد إضافة حزمة بلا بناء كامل |
| `network_error` | «لا يوجد اتصال بالإنترنت» ← **هذه وحدها** رسالة الإنترنت |
| ألغى المستخدم النافذة | لا رسالة أصلاً |
| غير ذلك | نوع الخطأ يظهر في وضع التطوير، وكل شيء يُطبع في اللوج بوسم `🇬` |

## 10. شريحة ب — المحادثات: عزل الحسابات على الجهاز 👤

**المطلب:** جوّال واحد قد يستعمله أكثر من حساب (وزائر). كل حساب يرى **محادثاته وحده**.

**العلّة:** المحادثات كانت تُحفظ في Hive **بلا مالك**، فأي حساب يفتح التطبيق يرى سجلّ من سبقه.

### التنفيذ
| الطبقة | التغيير |
|---|---|
| `ChatConversation` | حقل `ownerUid` — `@HiveField(10, defaultValue: "")`، والمولّد أُعيد توليده |
| `ChatStorage` | **كل** استعلام يأخذ `ownerUid`: `getAllConversations` · `getConversationsByScope` · `countInScope` · `getOwnedConversation` |
| المسح | `clearForOwner(uid)` بدل `clearAll` — «مسح محادثاتي» و«حذف الحساب» لا يمسّان حساباً آخر على الجهاز |
| الترحيل | `adoptOrphans` لمرة واحدة: محادثات ما قبل الحقل تُنسب لأول حساب يسجّل الدخول (**لا لزائر**) |

**النطاق والمالك يعملان معاً:** `(المالك) × (صف + مسار + مادة + فرع + وضع)`.

**الزائر:** له `uid` مجهول ثابت ⇒ سجلّه منفصل تماماً. وحين يسجّل يبقى الـuid نفسه (`linkWithCredential`) ⇒ **محادثاته تنتقل معه بلا نسخ ولا فقدان**.

### المزامنة — للمقياس والفاتورة
| # | التحسين | الأثر |
|---|---|---|
| 1 | **تجميع الكتابات** بمهلة 3 ثوانٍ | الردّ الواحد كان يستدعي الحفظ 3 مرات ⇒ **3 كتابات Firestore صارت واحدة** |
| 2 | `flushNow()` عند مغادرة الشاشة وتسجيل الخروج | لا تضيع آخر رسالة من النسخة السحابية |
| 3 | **سحب تلقائي على جهاز جديد** | أول دخول بلا محادثات محلية ⇒ استعادة واحدة (بلا أي مستمعين) |
| 4 | `revision` (إشارة محلية) | تصل محادثات من السحابة ⇒ الشاشة المفتوحة تُحدِّث قائمتها فوراً |
| 5 | **سقف 400 رسالة** في المستند | ⚠️ يطابق `validConversation()` في القواعد — رفع أحدهما دون الآخر **يُفشل المزامنة صامتةً** |

### الأمان
`match /conversations/{convId}` صارت قاعدة مستقلة بتحقّق شكل: `messages is list ≤ 400` · `grade` بين 1 و3 · `track` من القائمة · حدود أطوال العنوان والمادة و`scope_key`.
✅ **تحقّق فعلي:** `firebase deploy --only firestore:rules --dry-run` ⇒ *rules file firestore.rules compiled successfully* (بلا نشر).

### الاختبارات (54 فرونت — منها 13 جديدة)
`chat_storage_owner_test.dart` على Hive حقيقي في مجلد مؤقت: كل حساب يرى محادثاته · الزائر منفصل · **حساب لا يفتح محادثة غيره ولو عرف معرّفها** · النطاق+المالك معاً · «مسح محادثاتي» لا يمسّ الآخر · محادثة بلا مالك لا تظهر لأحد قبل التبنّي · التبنّي لا يلمس محادثات غيره · الحفظ بلا `ownerUid` لا يمحو المالك القائم.
