# 🚀 ديمو "مسار المستقبل" — النسخة الشاملة (Front-End فقط)

نسخة عرض (Demo) كاملة تحاكي المنصة **من البداية إلى النهاية** لعرضها على الشركة/المؤسسة.
كل شيء **محاكاة بالكامل** — لا Backend ولا Firebase ولا Firestore. البيانات وهمية والحالة بالذاكرة.
**لا تمسّ التطبيق الأصلي إطلاقاً** (نقطة دخول منفصلة).

## 🗺️ التدفق الكامل
Splash (نبض الشعار + مراحل تهيئة) ← Onboarding (٤ صفحات + روبوت متحرك) ← التوثيق (تسجيل/حساب جديد + اختيار الصف + دخول كزائر) ← **الرئيسية**:
- **هيدر**: صورة الطالب + تحية حسب الوقت + شارة الصف + جرس + إعدادات.
- **بانر متحرك** (تقليب تلقائي كل ٤ ثوانٍ).
- **بطاقة التعليم البطل** (بروبوت) + **٣ بطاقات**: المنح · اختبر نفسك · الخدمات + **بطاقة "أكمل من حيث توقفت"**.
- **روبوت عائم** (FAB) في كل شاشة: فقاعة تعليمات أول زيارة + شات محاكى.

**الأقسام:**
- **التعليم**: شرائح الصفوف الثلاثة + المواد + الأوضاع (شرح/تلخيص/سؤال/وزاري) + شات ذكي بمحاكاة كتابة، مع **مايك 🎤 وكاميرا 📷 وأسئلة مقترحة وأزرار حفظ/مشاركة/استماع** (كلها محاكاة) + حد الزائر (٥ أسئلة).
- **المنح**: بحث + فلاتر + شارة حالة (مفتوح/قريباً/مغلق) ← تفاصيل بتبويبات (نبذة/متطلبات/مواعيد/تقديم) + **مساعد المنحة** (شات) + "ذكّرني قبل الإغلاق".
- **اختبر نفسك**: اختبار مادة (سؤال-بسؤال + تصحيح فوري + **خريطة نقاط الضعف** مع زر "اشرح لي" يفتح الشات) + **اختبار الميول** (١٥ سؤالاً ← تقرير بمجالك الأنسب + تخصصات + منح مقترحة).
- **الخدمات**: بطاقات ← تفاصيل + زر واتساب.
- **الإعدادات**: ملف/صف + مظهر (داكن + حجم خط) + صوت + إشعارات + بيانات + تسجيل خروج.

## ▶️ التشغيل في كروم

> ⚠️ **مهم:** بناء/تشغيل ويب فلاتر يفشل إذا كان مسار المشروع فيه **أحرف عربية** ("سطح المكتب") — أداة `impellerc` لا تكتب في مسار غير إنجليزي. قيد بيئة يصيب كل المشروع، لا علاقة له بالكود.

**انسخ لمسار إنجليزي ثم شغّل:**
```bash
# انسخ مجلد المشروع كاملاً إلى C:\masar_demo (مرة واحدة)، ثم:
cd C:\masar_demo
flutter pub get
flutter run -d chrome -t lib/future_masar_demo.dart
```
**(الأفضل):** انقل المشروع نهائياً خارج OneDrive/المسار العربي إلى `C:\projects\ye_student_tutor` فيشتغل الويب بلا نسخ.

الهوية: نفس ألوان وثيم التطبيق الأصلي (`core/theme`) وأنيميشنه (`FadeInSlide`, `TypewriterText`, `TypingIndicator`).
