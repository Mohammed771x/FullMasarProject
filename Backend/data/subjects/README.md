# 📚 أين أضع ملفات المحتوى؟

## القاعدة الواحدة

```
data/subjects/{المادة}/
├── grade1/                      ← الأول الثانوي (موحّد — بلا مجلد مسار)
│   ├── lessons_mode/            📖 وضع الدروس
│   └── unit_mode/               📄 وضع الوحدات/الصفحات
├── grade2/
│   ├── علمي/{lessons_mode, unit_mode}/
│   └── أدبي/{lessons_mode, unit_mode}/
├── grade3/
│   ├── علمي/{lessons_mode, unit_mode}/   ← محتواك الحالي هنا
│   └── أدبي/{lessons_mode, unit_mode}/
└── exams/                       ← 📝 بنك الوزاري (كما هو — لا تلمسه)
```

**مثال — الإنجليزي:**
```
انجليزي/grade1/lessons_mode/           ← قالب
انجليزي/grade2/علمي/lessons_mode/       ← قالب
انجليزي/grade2/أدبي/lessons_mode/       ← قالب
انجليزي/grade3/علمي/lessons_mode/انجليزي.json   ← ✅ ملفك الحالي
انجليزي/grade3/أدبي/lessons_mode/       ← قالب
```

> 🟢 **كل (صف، مسار) معزول تماماً** — محتوى الثالث العلمي لا يظهر لغيره.
> 🟢 **تُنشأ المجلدات فقط حيث المادة مقررة** — الأحياء بلا مجلد `أدبي` مثلاً.
> 🟢 **ترمي الملف → الوضع يظهر في التطبيق تلقائياً.** بلا سطر كود ولا إعادة نشر.
> 🟢 **المجلد الفارغ** فيه `_TEMPLATE.json` — انسخه وسمِّه باسم المادة واملأه.
> 🟢 **مادة بلا محتوى** تعرض للطالب «📁 قيد الإضافة 🚧» بلطف — لا تعطُّل ولا خطأ.

## 📖 وضع الدروس — لك خياران (متكافئان تماماً)

### خيار (أ) — ملف واحد
```
تاريخ/grade1/lessons_mode/تاريخ.json
```
```jsonc
{
  "كتاب": "تاريخ - الأول الثانوي",
  "الوحدات": [
    { "اسم_الوحدة": "الحضارات القديمة",
      "الدروس": [
        { "اسم_الدرس": "حضارة سبأ",
          "ملخص_قصير": "...",
          "الأجزاء": [ { "نوع": "نقاط_مهمة", "اسم_الجزء": "...", "المحتوى": ["..."] } ] }
      ] }
  ]
}
```
> هذه **نفس صيغة الفيزياء والكيمياء والعربي الحالية** — انظر `فيزياء/grade3/علمي/lessons_mode/فيزياء.json`.

### خيار (ب) — ملف لكل درس
```
جغرافيا/grade1/lessons_mode/
└── تضاريس اليمن/                 ← اسم المجلد = اسم الوحدة
    ├── السهل الساحلي.json        ← اسم الملف = اسم الدرس
    └── المرتفعات الجبلية.json
```
> هذه **نفس صيغة الرياضيات الحالية** — انظر `رياضيات/grade3/علمي/lessons_mode/تفاضل/`.

**استخدم أيّهما أسهل عليك في كل مادة.** لو وُجد ملف واحد صالح فهو الأسبق.

## 📄 وضع الوحدات/الصفحات — ملف واحد
```
احياء/grade3/علمي/unit_mode/احياء.json
```
```jsonc
[                                    // ← الجذر قائمة [ ] لا كائن { }
  { "رقم_الوحدة": 1,
    "اسم_الوحدة": "التنظيم الهرموني",
    "الصفحات": [ { "رقم_الصفحة": 41, "نص_الصفحة": "النص الكامل للصفحة..." } ] }
]
```
> هذه **نفس صيغة الأحياء الحالية** — انظر `احياء/grade3/علمي/unit_mode/احياء.json`.

## ⭐ صيغة الدرس **حرة تماماً**

داخل الدرس اكتب **أي حقول تريدها بأي أسماء**. النظام يحوّل الدرس كاملاً إلى نص للموديل مهما كان شكله.

الفيزياء تستخدم `الأجزاء`، والرياضيات `تعريفات/حالات/أمثلة_محلولة`، والإنجليزي `القواعد/أمثلة_تطبيقية` — **الثلاثة تعمل بلا أي تعديل**.

**المطلوب فقط:** `اسم_الوحدة` و`اسم_الدرس` (أو اسم المجلد/الملف) — لأن الطالب يراهما في القائمة.

## 📏 حدود عملية

| البند | الحد |
|---|---|
| حجم الدرس الواحد | 30,000 حرف (أكبر درس حالي 5,385 — هامش واسع؛ الزائد يُقص بتنويه) |
| الترميز | **UTF-8 بلا BOM** |
| ملفات تُتجاهل | ما يبدأ بـ `_` أو `.` — لذلك `_TEMPLATE.json` آمن |
| ترتيب العرض | أبجدي. سمِّ المجلدات `01-الوحدة الأولى` لترتيب محدد |

## ✅ كيف تتأكد أن ملفك اشتُغل؟

```bash
curl -s -G "http://127.0.0.1:8000/content/capabilities" --data-urlencode "subject=تاريخ" --data-urlencode "grade=1" --data-urlencode "track=عام"
```
الرد يوضح الوضعين المتاحين وشجرة الوحدات/الدروس كما سيراها الطالب.
