## ✅ الدفعة الثانية — بأمر المالك: «عدّل كل عيب» (`apply_fixes_2.py`، ٣٧ استبدالاً)
القاعدة: العيبُ الرسميّ (حلٌّ لا يطابق سؤاله، خياران متطابقان، قيمٌ معكوسة، نسخٌ مختلّ) يُصلَح؛
والمعلومةُ الوصفية لا تُصلَح إلا إن خالفت **نصَّ الدرس** المخزون.
- **حلٌّ يُطابَق على السؤال كما هو:** س³ + س⁻¹ (±(١/٣)^(١/٤)) · ع = ٢س ⇒ ١/س · الحد الأعلى لـ∫لو س = هـ - ١ ·
  ت^(٤ن-٣) = ت ✓ · (١٢ - ٢√٣ت)/(√٣+٣ت) طوله √١٣ · الجذر الآخر ٢ - ٤ت.
- **سؤالٌ أُعيد لأصله بدليلٍ من الملف نفسه:** «h ع» ← «h ف» (نظيره) · 14,45 ← 12,75 (أرقام الحل) ·
  «٢٧جذر + ٩ت» ← «جذر٢٧ + ٣ت» (ثلاثة نظائر) · ملاحظةُ «تم تصحيحها من قبل الطالب» حُذفت.
- **كيمياء بنصّ الدرس:** القاعدية = الأمين · اختزال الجلوكوز = سوربيتول · C6H12O5 ← C6H12O6 ·
  قيمٌ معكوسة الترتيب في ٥ رؤوس (Mg/Cu، Ni/Fe، Sn/Ag، CaO/CO2، NO2/H2O) · 10N5 ← 10B5 · «المكتسبة» ← «المفقودة».
- **فيزياء:** «بالأقمار الصناعية» ← الصواريخ ذاتية الدفع · تكبير الباعث المشترك: «من تيار القاعدة» ·
  سبب التصادم غير المرن · جذر3 ≈ 1,732 (173,2 م/ث).
- **بنية:** أُزيل غلاف «خواص الترافق» ⇒ ١١ سؤالاً بدل سؤالٍ فارغ (مُثبتٌ عبر `get_math_exam_questions`).

## ⏸️ تُرك عمداً
- كيمياء ٢٠٢٥: «H2O(L)→H2O(g) تفاعل ماص: خطأ» — الدرس يسمّيه «تغيراً حرارياً فيزيائياً» (ΔH = +44) فلعلّ الخطأ في كلمة «تفاعل».
- فيزياء ٢٠٢٤: «جرس الإنذار بالأشعة فوق البنفسجية» — نصُّ الدرس يقولها حرفياً.

## (أرشيف) ما كان مُعلَّقاً قبل الدفعة الثانية
- فيزياء ٢٠٢٥: «h ع» و«ك ت نق λ» وحدتاهما مختلفتان (نظيره يقول «h ف»).
- فيزياء ٢٠٢٥: إثارةٌ بطاقة 14,45 > 13,6 أ.ف ⇒ تأيُّن؛ الحل يُخرج +0,85 ثم يستعمل -0,85 (الأرجح 12,75).
- تفاضل ٢٠١٨: د = س³ + س⁻¹ نقاطها الحرجة ±(١/٣)^(١/٤) لا ±١ (الحل يوافق س³ + ٣س⁻¹).
- تفاضل ٢٠١٨: ص = لو|ع|، ع = ٢س ⇒ ص' = ١/س؛ الحل «٢ ظتا ٢س» يوافق ع = جا ٢س.
- تكامل ٢٠٢٤: «الحد الأعلى لـ ∫(١←هـ) لو س» — ١ هو القيمة الدقيقة، والحد بالمبرهنة هـ-١ (ليس بين الخيارات).
- جبر: «ت^٤ن - ٣ = ت» — إن كان الأُس (٤ن-٣) فالعبارة صحيحة والحل (×).
- جبر (موضعان): «أحد جذري عدد مركب ٤ت-٢» ⇒ الآخر ٢-٤ت؛ الحل هو المرافق (يوافق «جذري معادلة»).
- جبر (موضعان): ع = (١٢ - ٢√٣ت)/(√٣+٣ت) طولُه √١٣، والحلان [٤، ٣ط/٢] و[١، ط/٦] متناقضان.
- جبر: نسخةٌ فيها «٩ت» بدل «٣ت» فلا يصحّ «ع = ٣».
- كيمياء ٢٠٢٥ (غير حسابي): «المجموعة القاعدية = الكربوكسيل» والصواب الأمين.
