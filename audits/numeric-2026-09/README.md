# التدقيق الحسابي الشامل — قسم التعليم ثم «اختبر نفسك»

بدأ: 2026-09-24 · بطلب المالك: «كل شيء فوقه أرقام يُفحص ويُصلح، ١٠٠٪، بيدك لا بالـAPI».

## القواعد (قرارات المالك — لا تُعاد مناقشتها)
1. **الفحص بعين الموديل نفسه** قراءةً درساً درساً — لا DeepSeek ولا أي API.
2. **الصحيح يُكتب حتى لو كان الكتاب مخطئاً.** خطأ الكتاب يُصحَّح في الشرح وفي نصّ المصدر.
3. **النطاق:** قسم التعليم كاملاً أولاً = ثلاث طبقات:
   - (أ) الشروح المخزونة `Backend/data/explanations/**`
   - (ب) نصّ الكتاب في وضع الدروس `Backend/data/subjects/*/grade*/**/lessons_mode/*.json`
   - (ج) نصّ الكتاب في وضع الوحدات `…/unit_mode/*.json` (صفحات مستقلة باستخراج مختلف وأخطاء مختلفة!)
   ثم **يتوقّف ويُبلغ المالك** قبل «اختبر نفسك».
4. لماذا الفحص الآلي السابق لا يكفي: `tools/arith_check` لم يكن يتحقّق إلا من **١٩٧ من ٤٧١٠** مساواة رقمية
   في شروح الفيزياء/الكيمياء/الرياضيات (٤٪) — كل سطر فيه وحدة أو رمز عربي كان يسكت عنه.

## الأدوات (في هذا المجلد)
| الأداة | العمل |
|---|---|
| `nx.py FILE START [BUDGET]` | يعرض الشروح التي فيها أرقام بدءاً من فهرس، ويطبع NEXT |
| `show.py FILE A B` | يعرض الدروس [A,B) كاملة |
| `fix.py FILE IDX 'old' 'new' 'why'` | إصلاح في شرح مخزون (موضع واحد بالضبط) ⇒ `fixes.jsonl`. `FIXALL=1` يسمح بعدّة مواضع — ⚠️ اطبع كل المواضع قبله (أصاب مرّةً مقام الدالة نفسها مع مقام مشتقتها) |
| `srcfix.py FILE 'old' 'new' 'why'` | إصلاح في نصّ المصدر الخام ⇒ `source_fixes.jsonl` |
| `hashcheck.py --compare baseline_valid.json` | أيّ شرح سقط تسليمُه منذ خط الأساس (يجب أن يبقى ٠) |
| `rehash.py` | بعد إصلاح المصدر: يعيد بصمة الشروح التي سقطت بسببه فقط |

⚠️ `hashcheck`/`rehash` تحتاج `Backend/.venv/bin/python`. خط الأساس: **٨١٥ شرحاً كلها تُسلَّم**.
⚠️ بعد **كل** دفعة `srcfix` شغّل `rehash.py` ثم `hashcheck --compare` ⇒ يجب `LOST 0`.
⚠️ صيغ الكيمياء تُكتب يونيكود (H₂O) لا `\sub`؛ لكن الصيغة العامة `C\sub{n}H\sub{2n+2}` مقصودة (لا يوجد ₙ مؤكد في الخط).
⚠️ السطر الذي يبدأ بـ«- » يُرسم نقطة قائمة ⇒ إشارة السالب تضيع.
⚠️ **تصحيح (فُحص في math_text.dart):** الكسر داخل الكسر **يُرسم** (المحلِّل تراجعي `_group`→`_nodes`). بضعة إصلاحات مبكّرة حوّلته إلى «÷» بسبب «لا يُرسم» — التعديل مكافئ رياضياً وسليم العرض، لكن السبب المسجّل خاطئ. **لا تغيّر الكسور المتداخلة بعد الآن.**
⚠️ `\chem{…}` يُمرَّر خاماً لـChemNode: لا تضع داخله `\sup` أو `_`؛ واكتب الأيون `N³⁻` خارجه (\chem{N3-} يُرسم N₃).

## أصناف العيوب التي وُجدت (للبحث عنها في الطبقات الباقية)
- أخطاء حساب صريحة (٤٣٫٤٦ بدل ٤٣٫٤٤) وأجوبة مخترعة لأسئلة لا جواب لها في الكتاب.
- أخطاء الكتاب نفسه: ١ جول = ١٠ إرج، وزن Sr ٧٨٫٦٢، كثافة ٢٦٠، ٢٢١٧٫٣، شيكاغو ١٠٨٦، السكستليون…
- أرقام الأرقام المعنوية تخالف القاعدة التي يذكرها الدرس نفسه.
- صح/خطأ: الشرح يكتب العبارة **مصحَّحة** ويضع بجوارها (X) ⇒ حقيقة صحيحة موسومة خطأ. **منهجي**: وُجد في كيمياء١ و٢ وفيزياء٢ — افحص كل «تقويم الوحدة» في **كل المواد** مقابل نص الكتاب.
- الشرح يغيّر سؤال الكتاب ثم يحلّه (Fe₃O₄+CO→FeO صارت →Fe). قارن المعطيات بالكتاب دائماً.
- قانون خاطئ لنوع العملية (تمدد بويل حُسب ض×Δح).
- تشوّه ترميز: `NO³⁻`→NO₃⁻، `N⁻ميثيل`→N-ميثيل، `CH₃²⁻ الهلجنة` (سطر «2-» التصق)، `\sup{-}\frac{…}`.
- إشارة سالبة ضائعة، `\frac{2l+1}{1}`، رمزٌ مجزّأ حول الكسر (`Δ \frac{ل}{…}` ⇐ `\frac{Δ ل}{…}`، `\frac{١}{سع} ك` ⇐ `\frac{١}{سع ك}`، `د \frac{ص}{د} س` ⇐ `\frac{د ص}{د س}`).
- عنوان مزدوج `### ###`، و`ط` مكان π، و`\sup{-}` رابطةً (تُرسم شحنة سالبة)، و`-O⁻`/`-COO⁻` رابطةً رُسمت شحنة.

## أدوات الطبقتين (ب)/(ج) — مصادر الكتاب (أُضيفت 2026-09-25)
- `srcmany.py FILE PATCH.json` — استبدال نصي في ملف مصدر؛ PATCH قائمة {old,new,why,n?}. شغّل أولاً `DRY=1` ليطبع عدد المواضع. لا يُعيد تنسيق الملف.
- `srcset.py FILE PATCH.json` — استبدال عنصر JSON كامل (أمثلة دروس الرياضيات) مع الحفاظ على المسافة البادئة.
- `srcconfig.py FILE` — توحيد صيغة التوزيع الإلكتروني 2S2/2S^{2} ⇒ 2s².
- `verify.sh` — rehash ثم hashcheck (يجب LOST 0) — شغّله بعد كل دفعة.
- `arith.py [PATH]` — يعيد حساب «أ op ب = ج» في المصادر ويطبع المختلف (مرشِّح).
- `srccmp.py SUBJECT [--rev]` — أرقام الدروس الغائبة عن صفحات الكتاب (unit_mode) مع السياق (مرشِّح).
- ⚠️ لا تكتب ملف مصدر بـ json.dump: بعض الملفات بتنسيق غير قياسي فيُعاد تنسيق الملف كله (حدث مع فيزياء 2 unit_mode ورُدّ بإعادة تشغيل source_fixes.jsonl على HEAD).
- ⚠️ السياق الذي يطبعه src.py يدمج الأسطر؛ النص الخام فيه `\n` حرفية وأرقام فارسية/عربية — انسخ `old` من الملف لا من المخرجات المترجمة.
