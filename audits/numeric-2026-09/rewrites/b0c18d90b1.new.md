حيّاك الله — نحلّ اليوم التمارين العامة على التكامل وتطبيقاته.

### 🎯 الفكرة الكبرى
هذه التمارين تجمع كل ما في الوحدة: تكامل القوى، وتبسيط المقدار قبل التكامل (فكّ الأقواس، وقسمة الحدود، وتحويل الجذور إلى أسس)، ثم التكامل المحدد، وإيجاد الدالة الأصلية من نقطة، وحساب المساحات.

### أولاً: التكاملات غير المحددة
- [١] ∫ (س\sup{٢} - س + ٢) دس = \frac{س\sup{٣}}{٣} - \frac{س\sup{٢}}{٢} + ٢س + ث
- [٢] ∫ (\frac{٢}{ع\sup{٢}} - \frac{٣}{ع\sup{٣}}) دع = ∫ (٢ع\sup{-٢} - ٣ع\sup{-٣}) دع = -\frac{٢}{ع} + \frac{٣}{٢ع\sup{٢}} + ث
- [٣] ∫ ص(ص + ١) دص = ∫ (ص\sup{٢} + ص) دص = \frac{ص\sup{٣}}{٣} + \frac{ص\sup{٢}}{٢} + ث
- [٤] ∫ (\frac{١}{س\sup{٢}} - \frac{١}{\sqrt{س}} + \frac{س}{٢}) دس = ∫ (س\sup{-٢} - س\sup{-\frac{١}{٢}} + \frac{١}{٢} س) دس = -\frac{١}{س} - ٢\sqrt{س} + \frac{س\sup{٢}}{٤} + ث
- [٦] ∫ \frac{س\sup{٣} - ٢س}{س} دس = ∫ (س\sup{٢} - ٢) دس = \frac{س\sup{٣}}{٣} - ٢س + ث
- [٧] ∫ \frac{س\sup{٢} - ٢}{\sqrt{س}} دس = ∫ (س\sup{\frac{٣}{٢}} - ٢س\sup{-\frac{١}{٢}}) دس = \frac{٢}{٥} س\sup{\frac{٥}{٢}} - ٤\sqrt{س} + ث
- [٨] ∫ (\sqrt{س} - ٣\sqrt{س})\sup{٢} دس = ∫ (-٢\sqrt{س})\sup{٢} دس = ∫ ٤س دس = ٢س\sup{٢} + ث
 ⚠️ إن كان المقصود في الكتاب الجذر التكعيبي (\sqrt{س} - \sqrt[٣]{س})\sup{٢} فالتكامل = \frac{س\sup{٢}}{٢} - \frac{١٢}{١١} س\sup{\frac{١١}{٦}} + \frac{٣}{٥} س\sup{\frac{٥}{٣}} + ث
- [١٠] ∫ (٢س\sup{٢} + س) دس = \frac{٢س\sup{٣}}{٣} + \frac{س\sup{٢}}{٢} + ث
- [١٤] ∫ \frac{س\sup{٣} - ١}{س - ١} دس = ∫ (س\sup{٢} + س + ١) دس = \frac{س\sup{٣}}{٣} + \frac{س\sup{٢}}{٢} + س + ث (لأن س\sup{٣} - ١ = (س - ١)(س\sup{٢} + س + ١))

### ثانياً: التكاملات المحددة
- [٥] ∫ من -١ إلى ٢ س\sup{٢} دس = [ \frac{س\sup{٣}}{٣} ] = \frac{٨}{٣} - (-\frac{١}{٣}) = ٣
- [٩] ∫ من -٢ إلى -١ \frac{١}{س\sup{٢}} دس = [ -\frac{١}{س} ] = (١) - (\frac{١}{٢}) = \frac{١}{٢}
- [١١] ∫ من ١ إلى ٢ (س\sup{٣} - ٤س + ٥) دس = [ \frac{س\sup{٤}}{٤} - ٢س\sup{٢} + ٥س ] = (٤ - ٨ + ١٠) - (\frac{١}{٤} - ٢ + ٥) = ٦ - \frac{١٣}{٤} = \frac{١١}{٤}
- [١٢] ∫ من -١ إلى ١ (س\sup{٢} - س\sup{٣}) دس = [ \frac{س\sup{٣}}{٣} - \frac{س\sup{٤}}{٤} ] = (\frac{١}{٣} - \frac{١}{٤}) - (-\frac{١}{٣} - \frac{١}{٤}) = \frac{٢}{٣}
- [١٣] ∫ من ١ إلى ٣ \frac{س - ١}{\sqrt{س}} دس = ∫ (س\sup{\frac{١}{٢}} - س\sup{-\frac{١}{٢}}) دس = [ \frac{٢}{٣} س\sup{\frac{٣}{٢}} - ٢\sqrt{س} ] = (٢\sqrt{٣} - ٢\sqrt{٣}) - (\frac{٢}{٣} - ٢) = \frac{٤}{٣}

### ثالثاً: الدالة الأصلية
- [١٥] لإثبات أن ل دالة أصلية للدالة د نشتق ل ونتحقق أن ل'(س) = د(س) = -\frac{س}{٣}. (نص الدالة ل غير واضح في النسخة المنقولة؛ فمثلاً ل(س) = -\frac{س\sup{٢}}{٦} تحقق ذلك.)
- [١٦] د'(س) = ٤س\sup{٢} + ٣س والمنحنى يمر بالنقطة (-١ ، ١):
 د(س) = \frac{٤س\sup{٣}}{٣} + \frac{٣س\sup{٢}}{٢} + ث
 ١ = -\frac{٤}{٣} + \frac{٣}{٢} + ث ← ث = ١ + \frac{٤}{٣} - \frac{٣}{٢} = \frac{٥}{٦}
 د(س) = \frac{٤س\sup{٣}}{٣} + \frac{٣س\sup{٢}}{٢} + \frac{٥}{٦}
- [١٧] د(س) = س\sup{٢} - ٣س + ١ و ل(٠) = ٥:
 ل(س) = \frac{س\sup{٣}}{٣} - \frac{٣س\sup{٢}}{٢} + س + ث ، و ل(٠) = ث = ٥
 ل(س) = \frac{س\sup{٣}}{٣} - \frac{٣س\sup{٢}}{٢} + س + ٥

### رابعاً: الدوال المتشعبة والقيمة المطلقة
- [١٨-أ] د(س) = س عند س ≥ ١ ، و ٢ عند س < ١: نكامل كل قاعدة على فترتها، فالدالة الأصلية \frac{س\sup{٢}}{٢} + ث على [١ ، ∞[ و ٢س + ث على ]-∞ ، ١[، وفي التكامل المحدد نجزّئ عند س = ١.
- [١٨-ب] |س + ٢| = س + ٢ عندما س ≥ -٢ ، و = -(س + ٢) عندما س < -٢؛ نجزّئ عند س = -٢.
- [١٨-ج] |س - ١| = س - ١ عندما س ≥ ١ ، و = -(س - ١) عندما س < ١؛ نجزّئ عند س = ١.

### خامساً: المساحات
المساحة = مجموع القيم المطلقة لتكاملات الأجزاء، بعد التجزئة عند كل نقطة يقطع فيها المنحنى محور السينات داخل الفترة.
- [١٩] ص = س + ١ ، س = ٠ ، س = ٢: ∫ من ٠ إلى ٢ (س + ١) دس = [ \frac{س\sup{٢}}{٢} + س ] = ٤
- [٢٠] ص = ٣ ، س = -١ ، س = ٢: ∫ من -١ إلى ٢ ٣ دس = ٦ - (-٣) = ٩
- [٢١] ص = س\sup{٢} + ١ ، س = ١ ، س = ٢: [ \frac{س\sup{٣}}{٣} + س ] = \frac{١٤}{٣} - \frac{٤}{٣} = \frac{١٠}{٣}
- [٢٢] ص = س\sup{٢} - ١ ، س = -٢ ، س = ٢: يقطع المحور عند ±١، والأجزاء الثلاثة \frac{٤}{٣} + \frac{٤}{٣} + \frac{٤}{٣} = ٤
- [٢٣] ص = س\sup{٢} + ٢س - ٣ ، س = -٤ ، س = ٢: الجذران -٣ و ١، والأجزاء \frac{٧}{٣} + \frac{٣٢}{٣} + \frac{٧}{٣} = \frac{٤٦}{٣}
- [٢٤] ص = س\sup{٢} + ٢س + ٣: المميز ٤ - ١٢ < ٠ فلا يقطع المنحنى محور السينات (وهو فوقه دائماً)، ولا توجد منطقة محصورة بينه وبين المحور ما لم تُعطَ مستقيمات تحدّها.
- [٢٥] ص = ٩ - س\sup{٢} ، س = -٢ ، س = ٤: الجذر ٣ داخل الفترة، والجزءان \frac{١٠٠}{٣} + \frac{١٠}{٣} = \frac{١١٠}{٣}

### 🧠 ثبّتها
- بسّط قبل أن تكامل: فكّ الأقواس، واقسم على المقام حداً حداً، وحوّل الجذر إلى أس كسري.
- في المساحة: ابحث أولاً عن نقاط التقاطع مع محور السينات داخل الفترة، وجزّئ عندها.

### 🧭 الدرس في سطور
التمارين العامة تطبيق شامل على الوحدة: تكامل غير محدد بعد التبسيط، وتكامل محدد بالتعويض بالحدين، ودالة أصلية تحدد ثابتها نقطة معلومة، ومساحات تُجزّأ عند نقاط التقاطع مع المحور.
