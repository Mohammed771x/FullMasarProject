حيّاك الله — نشرح اليوم التمارين العامة على التكامل وتطبيقاته.

تتضمن هذه التمارين تطبيقاً شاملاً على قواعد التكامل غير المحدد، والتكامل المحدد، وإيجاد الدالة الأصلية، وحساب المساحات المحصورة تحت المنحنيات.

### أولاً: حساب التكاملات غير المحددة والمحددة
تعتمد هذه التمارين على قواعد تكامل القوى، وتوزيع التكامل على الجمع والطرح، وتبسيط الكسور قبل التكامل.

### ١. التكاملات غير المحددة
* [١] تكامل (س٢ - س + ٢) دس = \frac{س٣}{٣} - \frac{س٢}{٢} + ٢س + ج
* [٢] تكامل (\frac{٢}{ع٢} - \frac{٣}{ع٣}) دع = تكامل (٢ع\sup{-٢} - ٣ع\sup{-٣}) دع = \frac{٢ع\sup{-١}}{-١} - \frac{٣ع\sup{-٢}}{-٢} + ج = -\frac{٢}{ع} + \frac{٣}{٢ع٢} + ج
* [٣] تكامل ص(ص+١) دص = تكامل (ص٢ + ص) دص = \frac{ص٣}{٣} + \frac{ص٢}{٢} + ج
* [٤] تكامل (\frac{١}{س٢} - \frac{١}{\sqrt{س}} + \frac{س}{٢}) دس = تكامل (س\sup{-٢} - س\sup{-١}/٢ + \frac{١}{٢}س) دس = -س\sup{-١} - ٢س\sup{١}/٢ + \frac{س٢}{٤} + ج = -\frac{١}{س} - ٢\sqrt{س} + \frac{س٢}{٤} + ج
* [٦] تكامل \frac{س٣ - ٢س}{س} دس = تكامل (س٢ - ٢) دس = \frac{س٣}{٣} - ٢س + ج
* [٧] تكامل \frac{س٢ - ٢}{\sqrt{س}} دس = تكامل (س\sup{٣}/٢ - ٢س\sup{-١}/٢) دس = \frac{٢}{٥}س\sup{٥}/٢ - ٤س\sup{١}/٢ + ج
* [٨] تكامل (\sqrt{س} - ٣\sqrt{س})٢ دس = تكامل (-٢\sqrt{س})٢ دس = تكامل ٤س دس = ٢س٢ + ج
* [١٠] تكامل (٢س٢ + س) دس = \frac{٢س٣}{٣} + \frac{س٢}{٢} + ج
* [١٤] تكامل \frac{س٣ - ١}{س - ١} دس = تكامل (س٢ + س + ١) دس = \frac{س٣}{٣} + \frac{س٢}{٢} + س + ج

### ٢. التكاملات المحددة
* [٥] تكامل من -١ إلى ٢ س٢ دس = [\frac{س٣}{٣}] من -١ إلى ٢ = \frac{٨}{٣} - (-\frac{١}{٣}) = ٣
* [٩] تكامل من -٢ إلى -١ \frac{١}{س٢} دس = [-س\sup{-١}] من -٢ إلى -١ = [-\frac{١}{س}] من -٢ إلى -١ = (١) - (\frac{١}{٢}) = \frac{١}{٢}
* [١١] تكامل من ١ إلى ٢ (س٣ - ٤س + ٥) دس = [\frac{س٤}{٤} - ٢س٢ + ٥س] من ١ إلى ٢ = (٤ - ٨ + ١٠) - (\frac{١}{٤} - ٢ + ٥) = ٦ - ٣.٢٥ = ٢.٧٥
* [١٢] تكامل من -١ إلى ١ (س٢ - س٣) دس = [\frac{س٣}{٣} - \frac{س٤}{٤}] من -١ إلى ١ = (\frac{١}{٣} - \frac{١}{٤}) - (-\frac{١}{٣} - \frac{١}{٤}) = \frac{١}{١٢} + \frac{٧}{١٢} = \frac{٨}{١٢} = \frac{٢}{٣}
* [١٣] تكامل من ١ إلى ٣ \frac{س - ١}{\sqrt{س}} دس = تكامل من ١ إلى ٣ (س\sup{١}/٢ - س\sup{-١}/٢) دس = [\frac{٢}{٣}س\sup{٣}/٢ - ٢س\sup{١}/٢] من ١ إلى ٣ = (\frac{٢}{٣}(٣\sqrt{٣}) - ٢\sqrt{٣}) - (\frac{٢}{٣} - ٢) = (٢\sqrt{٣} - ٢\sqrt{٣}) - (-\frac{٤}{٣}) = \frac{٤}{٣}

### ثانياً: الدالة الأصلية

* [١٥] لإثبات أن ل دالة أصلية للدالة د(س) = -\frac{س}{٣}، يجب إيجاد مشتقة ل(س) والتأكد من مطابقتها لـ د(س).
* [١٦] لإيجاد د(س) علماً أن د'(س) = ٤س٢ + ٣س وتمر بالنقطة (-١ ، ١):
 د(س) = تكامل (٤س٢ + ٣س) دس = \frac{٤س٣}{٣} + \frac{٣س٢}{٢} + ج
 بالتعويض عن س = -١ ، د(س) = ١:
 ١ = \frac{٤(-١)}{٣} + \frac{٣(١)}{٢} + ج => ١ = -\frac{٤}{٣} + \frac{٣}{٢} + ج => ج = ١ + \frac{٤}{٣} - \frac{٣}{٢} = \frac{٦+٨-٩}{٦} = \frac{٥}{٦}
 إذن د(س) = \frac{٤س٣}{٣} + \frac{٣س٢}{٢} + \frac{٥}{٦}

* [١٧] لإيجاد ل(س) حيث د(س) = س٢ - ٣س + ١ و ل(٠) = ٥:
 ل(س) = تكامل (س٢ - ٣س + ١) دس = \frac{س٣}{٣} - \frac{٣س٢}{٢} + س + ج
 بما أن ل(٠) = ٥، فإن ج = ٥.
 إذن ل(س) = \frac{س٣}{٣} - \frac{٣س٢}{٢} + س + ٥

### ثالثاً: التكاملات الخاصة (الدوال المتشعبة والقيمة المطلقة)

* [١٨-أ] تكامل د(س) دس حيث د(س) = { س عند س >= ١ ، ٢ عند س < ١ }:
 يتم تقسيم التكامل عند النقطة ١.

* [١٨-ب] تكامل |س + ٢| دس: يتم تعريف القيمة المطلقة بحيث تكون (س+٢) إذا س >= -٢، و -(س+٢) إذا س < -٢.
* [١٨-ج] تكامل |س - ١| دس: يتم تعريف القيمة المطلقة بحيث تكون (س-١) إذا س >= ١، و -(س-١) إذا س < ١.

### رابعاً: المساحات المحصورة
لحساب المساحة المحصورة بين منحنى ص = د(س) والمستقيمات س = أ، س = ب، نستخدم التكامل المحدد: المساحة = تكامل من أ إلى ب |د(س)| دس.

* [١٩] ص = س + ١ ، س = ٠ ، س = ٢: المساحة = تكامل من ٠ إلى ٢ (س + ١) دس = [\frac{س٢}{٢} + س] من ٠ إلى ٢ = (٢ + ٢) - ٠ = ٤
* [٢٠] ص = ٣ ، س = -١ ، س = ٢: المساحة = تكامل من -١ إلى ٢ (٣) دس = [٣س] من -١ إلى ٢ = ٦ - (-٣) = ٩
* [٢١] ص = س٢ + ١ ، س = ١ ، س = ٢: المساحة = تكامل من ١ إلى ٢ (س٢ + ١) دس = [\frac{س٣}{٣} + س] من ١ إلى ٢ = (\frac{٨}{٣} + ٢) - (\frac{١}{٣} + ١) = \frac{١٤}{٣} - \frac{٤}{٣} = \frac{١٠}{٣}
* [٢٢] ص = س٢ - ١ ، س = -٢ ، س = ٢: المساحة = تكامل من -٢ إلى ٢ |س٢ - ١| دس.
* [٢٣] ص = س٢ + ٢س - ٣ ، س = -٤ ، س = ٢: المساحة = تكامل من -٤ إلى ٢ |س٢ + ٢س - ٣| دس.
* [٢٤] ص = س٢ + ٢س + ٣: المساحة تتطلب تحديد حدود التكامل من أصفار الدالة أو المعطيات.
* [٢٥] ص = ٩ - س٢ ، س = -٢ ، س = ٤: المساحة = تكامل من -٢ إلى ٤ |٩ - س٢| دس.
