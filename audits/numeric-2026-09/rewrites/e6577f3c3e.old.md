### 🎯 الفكرة الكبرى
درس التكامل المحدد هو جزء مهم من علم الرياضيات، حيث يُستخدم لحساب المساحات تحت المنحنيات. في هذا الدرس، سنتناول كيفية حساب التكامل المحدد للدوال الجبرية ودوال المقياس والمتعددة القواعد.

### التكامل المحدد
التكامل المحدد هو عملية رياضية تُستخدم لحساب المساحة تحت منحنى دالة معينة بين نقطتين محددتين. يُعبر عن التكامل المحدد بالصيغة التالية:

∫_{a}\sup{b} f(x) dx

حيث a و b هما حدود التكامل، و f(x) هي الدالة التي نريد حساب تكاملها.

#### ١. احسب التكاملات التالية:
لنبدأ بحساب بعض التكاملات المحددة.

**أ)** تكامل من ١ إلى ٢ (٣س\sup{٢} + ٢س) ds 

- **المعطيات**: f(x) = ٣س\sup{٢} + ٢س ، a = ١ ، b = ٢ 
- **القانون**: 

∫_{١}\sup{٢} (٣س\sup{٢} + ٢س) ds

- **خطوة التعويض**:
نحسب التكامل:

= [ س\sup{٣} + س\sup{٢} ]\sub{١}\sup{٢}

- **التعويض**:

= (٢\sup{٣} + ٢\sup{٢}) - (١\sup{٣} + ١\sup{٢}) = (٨ + ٤) - (١ + ١) = ١٢ - ٢ = ١٠

**ب)** تكامل من -٢ إلى ٣ (س\sup{٣} - ١) ds 

- **المعطيات**: f(x) = س\sup{٣} - ١ ، a = -٢ ، b = ٣ 
- **القانون**:

∫_{-٢}\sup{٣} (س\sup{٣} - ١) ds

- **خطوة التعويض**:
نحسب التكامل:

= [ \frac{س\sup{٤}}{٤} - س ]\sub{-٢}\sup{٣}

- **التعويض**:

= ( \frac{٣\sup{٤}}{٤} - ٣ ) - ( \frac{(-٢)\sup{٤}}{٤} - (-٢) ) = ( \frac{٨١}{٤} - ٣ ) - ( ٤ - (-٢) )

= ( \frac{٨١}{٤} - \frac{١٢}{٤} ) - (٤ + ٢) = \frac{٦٩}{٤} - ٦ = \frac{٦٩}{٤} - \frac{٢٤}{٤} = \frac{٤٥}{٤}

**ج)** تكامل من ٠ إلى ٨ \sqrt{(س+١)} ds 

- **المعطيات**: f(x) = \sqrt{(س+١)} ، a = ٠ ، b = ٨ 
- **القانون**:

∫_{٠}\sup{٨} \sqrt{(س+١)} ds

- **خطوة التعويض**:
نحسب التكامل:

= [ \frac{٢}{٣}(س+١)^{\frac{٣}{٢}} ]\sub{٠}\sup{٨}

- **التعويض**:

= \frac{٢}{٣}(٩^{\frac{٣}{٢}}) - \frac{٢}{٣}(١^{\frac{٣}{٢}}) = \frac{٢}{٣}(٢٧) - \frac{٢}{٣}(١) = ١٨ - \frac{٢}{٣} = \frac{٥٤}{٣} - \frac{٢}{٣} = \frac{٥٢}{٣}

**د)** تكامل من ١ إلى ٩ \sqrt{(س)} (س\sup{٢} - ٣س + ١) ds 

- **المعطيات**: f(x) = \sqrt{(س)} (س\sup{٢} - ٣س + ١) ، a = ١ ، b = ٩ 
- **القانون**:

∫_{١}\sup{٩} \sqrt{(س)} (س\sup{٢} - ٣س + ١) ds

- **خطوة التعويض**:
نحسب التكامل:

= ∫_{١}\sup{٩} (س^{\frac{٥}{٢}} - ٣س^{\frac{٣}{٢}} + \sqrt{(س)}) ds

- **التعويض**:
نحسب كل جزء:

= [ \frac{٢}{٧} س^{\frac{٧}{٢}} - \frac{٣}{٥} س^{\frac{٥}{٢}} + \frac{٢}{٣} س^{\frac{٣}{٢}} ]\sub{١}\sup{٩}

**هـ)** تكامل من ١ إلى ٤ ( \sqrt{(س)} + \frac{٢}{س} )\sup{٢} ds 

- **المعطيات**: f(x) = ( \sqrt{(س)} + \frac{٢}{س} )\sup{٢} ، a = ١ ، b = ٤ 
- **القانون**:

∫_{١}\sup{٤} ( \sqrt{(س)} + \frac{٢}{س} )\sup{٢} ds

- **خطوة التعويض**:
نحسب التكامل:

= ∫_{١}\sup{٤} ( س + ٤ + \frac{٤}{س} ) ds

- **التعويض**:
نحسب كل جزء:

= [ \frac{س\sup{٢}}{٢} + ٤س + ٤ |س| ]\sub{١}\sup{٤}

**و)** تكامل من -٢ إلى ٢ |س| ds 

- **المعطيات**: f(x) = |س| ، a = -٢ ، b = ٢ 
- **القانون**:

∫_{-٢}\sup{٢} |س| ds

- **خطوة التعويض**:
نحسب التكامل:

= ∫_{-٢}\sup{٠} -س ds + ∫_{٠}\sup{٢} س ds

- **التعويض**:
نحسب كل جزء:

= [ -\frac{س\sup{٢}}{٢} ]\sub{-٢}\sup{٠} + [ \frac{س\sup{٢}}{٢} ]\sub{٠}\sup{٢}

#### ٢. احسب تكامل من -١ إلى ٢ د(س) ds 
لنحسب تكامل دالة معطاة.

**أ)** د(س) = س\sup{٢} + ١ عند س ≥ ١ ، د(س) = ١ - س عند س < ١ 

- **المعطيات**: a = -١ ، b = ٢ 
- **القانون**:

∫_{-١}\sup{٢} د(س) ds

- **خطوة التعويض**:
نقسم التكامل إلى جزئين:

= ∫_{-١}\sup{١} (١ - س) ds + ∫_{١}\sup{٢} (س\sup{٢} + ١) ds

**ب)** د(س) = ٣س - ٢ 

- **المعطيات**: a = -١ ، b = ٢ 
- **القانون**:

∫_{-١}\sup{٢} (٣س - ٢) ds

- **خطوة التعويض**:
نحسب التكامل:

= [ \frac{٣س\sup{٢}}{٢} - ٢س ]\sub{-١}\sup{٢}

#### ٣. احسب التكاملات التالية:
**أ)** تكامل من -١ إلى ٢ |٢س - ١| ds 

- **المعطيات**: f(x) = |٢س - ١| ، a = -١ ، b = ٢ 
- **القانون**:

∫_{-١}\sup{٢} |٢س - ١| ds

- **خطوة التعويض**:
نقسم التكامل حسب نقطة الانكسار س = \frac{١}{٢} :

= ∫_{-١}^{\frac{١}{٢}} -(٢س - ١) ds + ∫_{\frac{١}{٢}}\sup{٢} (٢س - ١) ds

**ب)** تكامل من -٢ إلى ١ |س + ١| ds 

- **المعطيات**: f(x) = |س + ١| ، a = -٢ ، b = ١ 
- **القانون**:

∫_{-٢}\sup{١} |س + ١| ds

- **خطوة التعويض**:
نقسم التكامل حسب نقطة الانكسار س = -١ :

= ∫_{-٢}\sup{-١} -(س + ١) ds + ∫_{-١}\sup{١} (س + ١) ds

**ج)** تكامل من -٢ إلى ٢ |س\sup{٢} - ١| ds 

- **المعطيات**: f(x) = |س\sup{٢} - ١| ، a = -٢ ، b = ٢ 
- **القانون**:

∫_{-٢}\sup{٢} |س\sup{٢} - ١| ds

- **خطوة التعويض**:
نقسم التكامل حسب نقاط الانكسار س = -١ و س = ١ :

= ∫_{-٢}\sup{-١} -(س\sup{٢} - ١) ds + ∫_{-١}\sup{١} (١ - س\sup{٢}) ds + ∫_{١}\sup{٢} -(س\sup{٢} - ١) ds

### 🧭 الدرس في سطور
درس التكامل المحدد يركز على حساب المساحات تحت المنحنيات باستخدام التكامل. تعلمنا كيفية حساب التكاملات المحددة لدوال مختلفة، وكيفية التعامل مع الدوال التي تحتوي على قيم مطلقة. التكامل المحدد هو أداة قوية في الرياضيات تُستخدم في العديد من التطبيقات العملية.
